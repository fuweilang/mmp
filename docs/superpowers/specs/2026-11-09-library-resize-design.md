# 资料库目录宽度调整

用户选定：调整宽度并记住；悬浮提示、Pointer 拖拽、键盘调整；达到最小宽度保持展开。

## Approaches

采用资料库共享 React 组件内的独立分隔线，Web 与桌面共同生效；复用现有主题和 Pointer 事件，不引入布局库。WorkBuddy 的拖窄自动收起方案需要额外恢复入口，用户选择不采用。

## 行为

默认 280px、最小 200px、最大 480px，左右键每次 16px，Home/End 到边界。宽度保存在本机 localStorage 独立键中；非法缓存回到默认，存储受限仍可当次拖动。分隔线悬浮/拖动显示主题色，命中区 8px；使用 pointer capture，松手、取消、失去捕获与卸载清理拖动状态，恢复文本选择。小于等于 600px 保留现有纵向布局，隐藏分隔线；中等宽度按容器为内容至少保留 320px，记住的用户宽度不因窗口临时缩小而覆写。
