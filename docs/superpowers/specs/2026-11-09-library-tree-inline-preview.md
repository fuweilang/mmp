## 最终界面

左侧保留“最近使用 / 我的资料 / 企业共享 / 回收站”入口。我的资料与企业共享各有独立树，根标题再次点击切换展开和收起；子文件夹箭头独立切换，展开时按需读取对应分类、对应父目录的下一层。文件名使用相应格式图标、长名称省略并可查看完整名称。

点击文件只更新右侧预览。点击文件夹选中左侧位置并展开该分支，作为新建和上传目标；右侧不出现文件夹行或目录表格。第一次进入且尚未选择文件时，右侧显示“选择左侧文件以预览”的空态。切换分类清除上一分类的文件预览，防止误认仍在浏览旧文件；折叠树本身不关闭已选预览。

右侧顶部显示文件名、格式、版本及现有允许的操作，正文区域填满可用空间。预览直接嵌入当前资料库页面，不再弹出大对话框。下载、用于 AI 对话、版本、重命名、移动、分享、回收等现有操作迁移到文件操作菜单或预览工具栏；按原有 canManage 与服务端授权显示并执行。

搜索结果放在左侧导航区域，点击结果仍进入右侧预览；清空搜索恢复树及已有展开状态。最近使用展示文件快捷入口，回收站保留恢复和彻底删除操作。这两个入口不恢复右侧重复目录表格。

## 文件格式

| 格式 | 右侧内容 |
| --- | --- |
| Markdown | 标题、段落、列表、表格、代码等文档格式 |
| TXT、代码、JSON 等 | 文本或相应代码高亮，保留换行，支持滚动 |
| PDF | 原始页面、页数、翻页、缩放、适配宽度、可选择文字 |
| Word（doc/docx） | 原始文件转换为页面预览，保留可转换的段落、表格、图片与分页 |
| Excel（xls/xlsx）、CSV、TSV | 只读表格、工作表切换、行列、单元格格式及可支持的合并与尺寸 |
| PowerPoint（ppt/pptx） | 按幻灯片页面显示、翻页与缩放 |
| 图片 | 原图、缩放及适配区域 |
| 已支持的音视频 | 对应播放器 |
| 链接、无法渲染的文件 | 明确的格式说明和可执行操作；预览失败不能伪装为成功 |

预览能力与 AI 解析状态分开：例如 Excel 即使不能用于 AI 引用，仍应尝试格式预览。Office 字体缺失、复杂对象或表格特性无法完全还原时，沿用已有预览器的具体提示；不声称与 WorkBuddy 的私有转换服务在每个文件上像素一致。

## 实现路线

采用现有 React 客户端与文档预览器，通过声明的可复用 Factory 接入资料库。资料库负责文件授权、版本、加载与取消；预览器负责格式显示。新的全套预览引擎会重复现有 PDF、Excel 和 Office 工作；继续使用提取文字无法满足用户要求，因此不采用这两条路线。

1. `LibraryTree` 显式接受 mine/shared 分类，递归传递相同分类；不再固定查询 mine。保留分页、循环与深度保护。
2. `LibraryPanel` 使用双树、左侧搜索及右侧预览状态；以分类、nodeId、versionId 识别当前文件，过期请求不得覆盖新选择，拒绝访问或切换账号后不保留旧内容。
3. 新增读取受保护原始版本字节的入口，复用普通 download 授权。保持现有 inline=1 媒体白名单，不为文档预览开放任意 HTML 内嵌。
4. 文档预览包提供接收内容数据的 Factory，复用既有 PDF.js 与 FortuneSheet，实现不依赖聊天 Session/tab 的格式显示。跨 feature 不直接导入其私有组件，不为了预览而创建聊天或复制到 Session 目录。
5. Word/PPT 在账号绑定 Host 内授权读取确切的资料库版本，再调用现有 OfficeToPdf 服务；复用版本缓存、取消、大小限制、错误和字体提示。
6. 所有用户文案走现有本地化字典，保持 Web/桌面共用实现。生产发布和替换已安装桌面 App 不包含在本地实现中。

## 验收

- 双分类根和多层目录能展开/收起；状态互不干扰；根文件、同名文件和分页可访问。
- 左侧点击文件后右侧出现对应格式；右侧没有目录表格，没有预览弹窗。
- 切换文件、分类、版本或账号时，延迟成功与失败请求都不能覆盖当前预览；对象 URL 与转换任务正常释放。
- 用实际生成的小型 Markdown、PDF、Word、Excel、PPT、图片等文件验证标题/表格/样式/页数等可见特征，不能只检查渲染器名称或文件扩展名。
- 验证普通成员的本人私有、本人共享、他人共享与无权文件；共享子目录查询不得混入 mine 或超出原有权限。
- 窄窗口和明暗主题下检查左树滚动、长文件名、右侧工具栏及预览正文。
- 运行相关行为测试与完整构建，报告既有失败及实际未验收场景。
