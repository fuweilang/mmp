# 猛犸专家广场＋技能（第 1 阶段）可落地摘要

> 本版只做 UI/交互规范，不进入第 2/3 阶段实现。完整细节见落 mmp 的 `docs/design/expert-plaza-skills-ui-spec.md`。
> Web/桌面复用现有 Gallery；Admin 在现有官方智能体 CRUD 补关联技能，新增技能 CRUD。不另造安装市场，不改知识库。

## 现状落点
- 用户端：`mammoth-agent/packages/client/ui-official-agent-gallery/src/client/GalleryPage.tsx`、同名 `.module.css`、`locales.ts`。同一包覆盖 Web 与桌面，已有搜索/分类/卡片及新建会话。
- Admin：`ground/apps/frontend/src/views/admin/AdminOfficialAgents.vue` 延续官方智能体编辑；新建 `AdminOfficialSkills.vue` 供技能维护。`AdminOfficialKnowledge.vue` 不改。
- 色彩沿用各端已有 token 映射，避免两套页面/两套代码；ground 保持现有 Admin 组件风格。

## 用户端（拍板）
- 栏目标题「专家广场」，Tab「专家 / 技能」，默认专家；主按钮唯一入口，直接新建对话，**不做详情页/详情抽屉**。
- 专家卡仅头像 44×44、名称、一句白话用途、「开始对话」；技能卡仅名称、一句白话用途、「使用技能」（可选 40×40 方角浅底图标）。
- 卡名 15/22, 600/#333946；用途 13/20/#667085，最多两行；按钮 36px 高，13px；卡内 16、卡间距 12、最小高约 140、radius 0、1px #dfe5ef、hover #f8fafc。
- 主色 #415fff、hover #3450e6、浅底 #eef3ff；页底 #f5f7fb；正文 #667085，辅助 #8b909b，占位 #98a2b3；头像可为圆。优先映射现有 CSS 变量，暗色不能硬套浅色文字规则。
- 页标题 20/28、Tab 14px、底边 2px #415fff、点击区 40px。Tab 切换清空搜索，避免跨类型脏结果。
- 搜索全宽，placeholder「搜索专家/技能」，清空/Enter/300ms 防抖；只按名称与白话用途搜。分类只保留全部+少量易懂 chip；本 Tab 没内容的分类不渲染，禁止复杂标签。
- 布局复用现状：内容区最大 1080、padding 28px clamp(16px,3vw,40px) 40px；容器 >1100 三列，700–1100 两列，≤700 一列。窄屏搜索全宽、分类横向滚动、Tab 保留并排、按钮触控≥36px。

## 会话规则
- 开始对话：沿用专家 `startAgent` 创建新 session、切到新会话；旧会话保留。会话头轻标签「专家 · {name}」。
- 使用技能：也创建新 session 并绑定技能；会话头「技能 · {name}」。不是往旧会话叠加、也非安装商品。再次点同技能仍新建会话。
- 标签 24–28px、12px、浅底 #eef3ff、字 #415fff、radius 0，首版不可关闭。只表达来源，不展示版本/权限/工具清单。
- 实际执行技能时，轻提示「正在使用 {name}…」，完成后收为一行可展开摘要；不能放大块主色横条。

## 空/失败与启停
- loading「正在加载专家/技能…」；无数据「暂时还没有可用的专家/技能」；搜不到「没有找到相关专家/技能」。
- 加载失败「暂时无法加载，请稍后重试」＋「重试」；无权限/登录失效「登录已失效，请重新登录」。
- 创建失败：专家「无法开始对话，请重试」、技能「无法使用该技能，请重试」；不跳任何模型管理或设置页。
- 启用即全员可见可点；停用后该卡从新列表消失。旧会话保留历史来源；停用技能不在旧会话输入区默认启用，触发时提示「该技能暂不可用」。旧专家会话可继续对话，但不暗示停用技能可用。
- 专家关联技能停用后，专家卡继续（若启用）且不承诺该停用技能；技能 Tab 独立按技能启用状态显示。

## Admin（超管可懂）
- 「技能管理」紧挨官方智能体；表格=名称/用途/分类/状态/更新时间/操作。右上唯一主按钮「新建技能」。
- 新建/编辑仅：名称、用途（一句白话）、少量分类、启停、ZIP。新建须选包；编辑可保留旧包或换包。
- ZIP 固定步骤「选包→上传→校验→成功预览（名称/用途/版本）→可改名称用途→保存」。上传中防重复；取消关闭并放弃未保存上传。
- 校验失败「技能包无法识别，请换一个包再试」＋重选，不露出 stack/manifest/资源/沙箱/工具注册；不做技术调试台。
- 技能停用前若有关联，确认「停用后前台不再展示；已有对话不受影响」；删除前确认将解除专家关联再删除。业务流程语义由产品/后端最终明确，不在 UI 自造破坏性删除。
- 官方智能体现有编辑表单加「关联技能」多选、可搜索，只列当前启用技能；保存即更新关联。关联是专家能力，不决定技能 Tab 是否显示：启用技能即使没有被专家关联也独立可见。
- 第一版不展示企业分配/安装/评分/上传市场，不搬复杂 ZIP 或知识库扩容界面；知识库保持原页。
