# 猛犸「专家广场＋技能」极简 UI/交互规范（第 1 阶段）

> **文档性质**：只读调研后的 compact design spec，供李庚直接实现。  
> **范围**：用户端广场（Web + 桌面共享）＋ ground Admin 技能 CRUD / 专家关联技能。  
> **不做**：业务源码改动、Git、发布、测试、构建、浏览器验收、ZIP 后台管线细节页、知识库改版。  
> **品牌**：项目是猛犸 mmp，仅借用通用「方角工业风 / Element 少覆盖」方法，不搬 PeecAI 品牌与仓库约定。  
> **落盘**：本文件写于 box `/workspace/mammoth-expert-skill-ui-spec.md`。正文完成后同步本地 `docs/design/`。  
> **日期**：2026-11-06（Asia/Shanghai）

## 2. 核心决策（拍板）

1. **第一版不做详情页 / 详情抽屉 / 安装市场**。卡片主按钮直接新建会话。  
2. **点击一律新建对话**，绝不改写当前已打开的旧会话。  
3. **前台只展示启用内容**；停用项不出现在广场。  
4. **技能用户 UI = 广场卡片 + 会话头来源 + 调用中轻提示**；ZIP / manifest / 沙箱 / 工具注册对用户与超管表单均不可见。  
5. **知识库维持现有 Admin 页**，本阶段零改动。  
6. **不引入新主题机制**：客户端把 `#415fff` 映射进现有 CSS 变量；Admin 改 `layout.css` 主色 token（或对齐变量），少覆盖组件。

## 3. 页面结构：专家广场（用户端）

### 3.1 信息架构

```
专家广场
├── 页头：标题「专家广场」＋一句副文案（可选，一行）
├── Tab：专家 | 技能（默认「专家」）
├── 工具行：搜索（全宽）＋少量分类（横向 chip，可滚动）
└── 卡片栅格
```

禁止：安装 / 评分 / 销量 / 上传 / 购买 / 复杂标签云 / 刷新按钮占主视觉（刷新可藏次要或下拉，非必须）。

### 3.2 Tab

| 项 | 规范 |
| --- | --- |
| 文案 | 「专家」「技能」 |
| 默认 | 专家 |
| 形态 | 底边指示条（方角）：选中底边 2px `#415fff`，文字 `#333946` / 字重 500；未选 `#667085` / 400 |
| 高度 | 40px 点击区；字号 14px |
| 切换 | 只换下列表与空态文案；搜索关键字可保留或清空二选一——**建议切换 Tab 清空搜索，避免跨类脏结果** |
| 窄屏 | Tab 横向并排，不挤成下拉 |

### 3.3 搜索与分类

- 搜索：全宽；placeholder「搜索专家」/「搜索技能」随 Tab；支持清空、回车搜索；输入防抖约 300ms。  
- 分类：少量易懂 chip（复用现有 `common / productivity / content / sales / expertise / analytics` 中文：常用 / 工作提效 / 内容营销 / 销售增长 / 专业知识 / 数据分析）；首位「全部」。  
- chip：**方角 0**（替换现状 999px）；高 36px；padding `6px 12px`；字 12px；默认边框 `#dfe5ef`、字 `#667085`；选中底 `#eef3ff`、字 `#415fff`、边框 `#415fff` 或透明＋浅底。  
- 无分类数据的项：不渲染该 chip（或 count=0 仍显示由实现定——**建议 count=0 隐藏**，减噪音）。

### 3.4 专家卡（仅四要素）

| 元素 | 规范 |
| --- | --- |
| 头像 | 44×44；圆形允许（唯一圆角例外）；无图用首字＋浅底 `#eef3ff` / 字 `#415fff` |
| 名称 | 15px / 600 / `#333946`；单行省略 |
| 白话用途 | 取 `summary` 一句；13px / 400 / `#667085`；最多 2 行截断 |
| 主按钮 | 「开始对话」；primary；高 36px；字 13px |

**第一版卡片上删除**：版本号、能力标签、开场问题预览、「暂未开通」锁态、点卡片展开详情。整卡或主按钮均可触发开始。**主按钮为唯一入口**，卡身不可点，避免误操作与双路径。

### 3.5 技能卡

| 元素 | 规范 |
| --- | --- |
| 图标 | 可选 40×40 方角浅底图标区（非必须头像）；无图用技能首字方角块 |
| 名称 | 同专家 15/600/`#333946` |
| 白话用途 | 「能帮你做什么」一句；13/`#667085`；2 行 |
| 主按钮 | 「使用技能」；同 primary |

不做：安装态、已启用角标、权限说明、ZIP 相关文案。

### 3.6 详情策略（明确）

> **第一版：卡片直接新建会话，不做详情页、不做详情抽屉、不做「试试这些问题」面板。**  
> 现有 `GalleryPage` 的 `selected` 详情 section 与开场问题列表 **移除 / 停用**。若后端仍返回 `openingQuestions`，可在新建会话后由 Host 静默注入首条（产品另定）；**UI 不展示选择列表**。

## 4. Token 与视觉（方角工业风）

### 4.1 色板（目标值）

| Token 名（逻辑） | 色值 | 用途 |
| --- | --- | --- |
| primary | `#415fff` | 主按钮、选中 Tab 底边、链接 |
| primary-hover | `#3450e6` | 主按钮 hover |
| primary-light | `#eef3ff` | 浅底、chip 选中、头像 fallback |
| title | `#333946` | 标题、卡名 |
| body | `#667085` | 正文、用途 |
| secondary | `#8b909b` | 辅助说明 |
| placeholder | `#98a2b3` | 输入占位 |
| page | `#f5f7fb` | 页底（可映射现有 `--dsw-alias-bg-base` / Admin `--app-page-bg`） |
| card | `#ffffff` | 卡片 |
| row-hover | `#f8fafc` | 表行 / 卡 hover 浅底 |
| border | `#dfe5ef` | 分割与卡边 |
| danger | 沿用现有 error token | 失败文案 |

### 4.2 映射原则（不新主题机制）

**客户端（mammoth-agent）**

- 亮色：将项目现有品牌与主按钮 fill 相关变量映射到 `#415fff`；hover → `#3450e6`；浅底 → `#eef3ff`。  
- 暗色：**禁止**把正文硬编码成 `#415fff`；主色仅用于按钮/指示，文字继续走 `--dsw-alias-label-*`。  
- Gallery 局部：优先用 alias 变量；方角在本页 CSS 将 `border-radius` 收敛为 `0`（头像保持圆）。

**Admin（ground）**

- 在 `layout.css` 或对应当前品牌 token 中对齐 `#415fff` / `#3450e6` / `#eef3ff`；先核对现状，若已是该色则不重复改全局。  
- 圆角保持现有 `--el-border-radius-*: 0`。

### 4.3 字号 / 字重 / 间距

| 角色 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页标题 | 20 / 28 | 500 |
| 副文案 | 13 / 20 | 400 |
| Tab | 14 / 20 | 500 选中 / 400 未选 |
| 卡名 | 15 / 22 | 600 |
| 卡用途 | 13 / 20 | 400 |
| 按钮 | 13 / 20 | 500 |
| 空/错提示 | 13 / 20 | 400 |

间距：页头与 Tab `16px`；Tab 与搜索 `12px`；搜索与分类 `12px`；分类与栅格 `16px`；卡内 padding `16px`；卡间距 `12px`。

### 4.4 卡片尺寸与栅格

- 栅格：与现状一致——默认 3 列；大于 1100 → 3 列；700–1100 → 2 列；≤700 → 1 列（按**可用内容宽度**，不按物理屏幕型号臆断）。  
- 卡最小高度：约 140px（专家含头像行＋按钮）；不要固定死高导致空洞。  
- 卡边：`1px solid #dfe5ef` 或 `box-shadow: 0 0 0 1px …`；hover 背景 `#f8fafc`。  
- **radius: 0**（头像除外）。

### 4.5 触控与窄屏

- 主按钮 / Tab / chip 点击高度 ≥ 36px（理想 40px Tab）。  
- 搜索全宽；分类横向滚动，不折成多行迷宫。  
- 无桌面专属右侧复杂操作栏。

## 5. 加载 / 空 / 失败（前台）

| 状态 | 专家 Tab | 技能 Tab |
| --- | --- | --- |
| Loading | 「正在加载专家…」＋轻 spinner/StateDot | 「正在加载技能…」 |
| 空（无数据） | 「暂时还没有可用的专家」 | 「暂时还没有可用的技能」 |
| 空（无匹配） | 「没有找到相关专家」 | 「没有找到相关技能」 |
| 加载失败 | 「暂时无法加载，请稍后重试」＋「重试」 | 同左 |
| 鉴权失效 | 「登录已失效，请重新登录」 | 同左 |
| 新建会话失败 | 「无法开始对话，请重试」（不跳配置页） | 「无法使用该技能，请重试」 |
| 源不可用（已删/停用后历史会话） | 会话内轻提示：「该专家暂不可用」 | 「该技能暂不可用」 |

**启停规则**

- **启用**：出现在对应 Tab 列表，全员可见可点。  
- **停用**：新开会话的广场列表中消失；已有会话保留历史来源标签（只读展示名称），输入区**不**默认继续启用停用技能；旧专家会话仍允许继续对话，但不暗示已停用技能可用。若触发已停用技能 → 轻错误文案，**不**跳 Admin / 配置页。  
- 专家关联的技能若停用：前台技能 Tab 不出现；专家卡仍可「开始对话」，但不暗示该停用技能可用。

## 6. 新建对话与会话头

### 6.1 「开始对话」（专家）

1. 取当前工作区（沿用 `workspaceForNewSession`）；无工作区 → 文案「请先创建一个工作区，再开始对话」。  
2. 调用现有 `startAgent(agentId)`（或等价 API）**创建新 Session**。  
3. `openSession(newId)` 切到新会话；**当前旧会话内容与绑定不变**。  
4. 会话头展示来源标签：`专家 · {名称}`（短，单行；可截断）。

### 6.2 「使用技能」（技能）

1. 同样 **新建 Session**（不往旧会话塞技能）。  
2. 新会话绑定该技能为「已启用技能」来源；会话头：`技能 · {名称}`。  
3. 若产品定义为「带技能的空白对话」，输入区可预置一句不可见 system/skill 绑定；UI 只显示来源标签。  
4. **不重复启用同技能**：同一会话内同一技能只启用一次；再次从广场点同一技能 → 仍建**新**会话，而非在旧会话叠加。

### 6.3 来源标签本质

- 轻量、非营销：高度 24–28px；字 12px；底 `#eef3ff`；字 `#415fff`；方角 0；可关闭？**首版不可关闭**（避免用户误拆绑定）。  
- 仅展示「从哪来」；不展示版本号、授权企业、工具列表。

### 6.4 技能调用中轻提示

- 复用 / 对齐 `ui-skill` SkillRow 形态：一行「正在使用 {技能名}…」→ 完成收为可展开摘要。  
- 颜色走 secondary / tertiary，**不要**大块主色广告条。  
- 失败：一行错误摘要，可展开细节；无「去配置」入口。

## 7. Admin：技能管理（新建页）

### 7.1 导航与页头

- 路由建议：`/admin/official-skills`（名称实现可微调，需进 `router/index.ts` + `AppShell` 导航，紧挨「官方智能体」）。  
- 页头：标题「技能管理」；副文案「维护官方技能的名称、用途与启用状态。上传技能包后即可在专家广场使用。」  
- 主按钮：右上「新建技能」（primary）。

### 7.2 表格列（尽量少）

| 列 | 说明 |
| --- | --- |
| 名称 | 主识别 |
| 用途 | 一句白话，截断 |
| 分类 | 短标签 |
| 状态 | 启用 / 停用 |
| 更新时间 | |
| 操作 | 编辑、启停、删除（删除需确认） |

空态：「还没有技能」＋「新建技能」。  
失败：页顶 alert，不跳转。

### 7.3 新建 / 编辑字段（超管可懂）

1. 名称（必填）  
2. 用途（必填，一句白话，对应前台卡用途）  
3. 分类（少量下拉，与前台 chip 对齐）  
4. 启停（开关，默认启用）  
5. 技能包 ZIP（新建必填；编辑可「保留现包」或「重新上传」）

**不要**在表单暴露：manifest、resource、沙箱权限、工具注册、内部 ID 列表（只读技术字段可放「高级」但不做第一版）。

### 7.4 ZIP 顺序（固定向导语，同窗即可）

```
选包 → 上传 → 校验 → 成功预览（名称 / 用途 / 版本）→ 用户可改名称用途 → 保存
```

| 态 | 文案 / 行为 |
| --- | --- |
| 选包 | 「选择 .zip 技能包」 |
| 上传中 | 「正在上传…」不可重复点 |
| 校验失败 | 「技能包无法识别，请换一个包再试」＋保留重选；**不**展示堆栈 |
| 成功预览 | 只读预览版本号；名称/用途可改 |
| 取消 | 关闭对话框丢弃未保存上传 |
| 保存成功 | Toast「已保存」；回列表 |
| 关联专家仍引用时停用 | 允许停用；提示「已有专家关联此技能，停用后前台不再展示；已有对话不受影响」 |
| 删除 | 若仍被专家关联 → 二次确认「将从关联专家中移除并删除技能」 |

### 7.5 主按钮层级

- 页级主按钮：新建技能（1 个 primary）。  
- 对话框：保存 = primary；取消 = 次要。  
- 行内：文字按钮；危险操作（删除）用危险色文字。

## 8. Admin：官方智能体编辑补「关联技能」

- 落点：现有 `AdminOfficialAgents.vue` 新建/编辑对话框，在现有字段（头像、标识、类型、名称、简介、开场问题、提示词、工具范围、广场分类、能力标签…）中 **追加**：  
  - **关联技能**：多选；选项 = **已启用**技能列表；支持搜索。  
- 保存提示：「已保存关联。关联用于专家能力配置；前台「技能」Tab 仍按技能自身启用状态独立展示。」  

### 8.1 关联 ≠ 前台技能 Tab 的规则（清晰）

| 场景 | 专家 Tab | 技能 Tab |
| --- | --- | --- |
| 技能启用，且被专家 A 关联 | 专家 A 可开始对话（会话可带关联技能能力，由后端决定） | 该技能单独出现，「使用技能」新建会话 |
| 技能启用，无专家关联 | 不影响专家列表 | 仍出现在技能 Tab（全员可用） |
| 技能停用，仍挂在专家上 | 专家卡仍显示（若专家启用）；不在卡上列出停用技能名 | **不出现** |
| 专家停用/下架 | 不出现 | 不影响技能 Tab |
