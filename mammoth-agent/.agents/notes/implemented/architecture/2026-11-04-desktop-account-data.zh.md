# Agent Note：桌面客户端账号数据目录

Status: implemented

[English](2026-11-04-desktop-account-data.md) | 中文

## 问题

切换登录凭证没有切换桌面客户端的会话和工作区存储目录。同一操作系统用户下，不同账号因此看到了同一份本地历史。

## 决策

按已验证的登录服务、企业和用户身份隔离整个 Host 数据目录。账号提供方先读取用户资料，再向 Electron 发布私有身份；令牌中的企业声明必须与已验证的用户资料一起使用。路径使用身份哈希，不写入凭证。Electron 串行销毁旧页面、停止旧 Host、清空应用浏览器存储，再启动目标数据目录。旧 Host 的迟到通知不能改变新实例的身份。身份未确认时使用独立的未登录目录，并重试读取用户资料。

部署配置和登录存储保留在原安装位置。启动器的最终覆盖层将会话、数据域、附件和默认工作区文件固定到目标目录。旧历史不自动分配归属，因为原共享目录没有可靠的账号归属证据。[升级说明](../../../../docs/upgrade-guide/v0.2.2-alpha.2/desktop-account-data/guide.zh.md)介绍了这一行为。既有[内嵌平台浏览器存储](2026-09-22-platform-browser-storage.zh.md)策略保持独立；本决策处理 Host 任务数据和应用页面。

## 验证

针对性测试覆盖身份目录、企业变化、账号切换与恢复、停止失败、旧通知、身份重试、启动目录和无归属历史保留。主进程集成测试检查先销毁页面、再替换进程的顺序。
