# @mammoth-ai/mmp-official-agent-gallery

[English](README.md) | 中文

## 概要

Host 根据已发布专家或创建者专属的不可变预览创建原生标准会话。冻结的角色、技能、检索策略和生成模型不会扩大能力权限；原生文件、终端、技能及其授权机制保留。云端工具范围只控制额外云工具。

## Remote API

`create` 接收专家和工作区；`createPreview` 还接收不可变预览 ID，由图库客户端的 `expertPreview` URL 入口消费。两者均装载标准预设。Host 协商执行协议 2，并兼容原有精确旧响应。预览通过正常 Ground 适配器并携带预览用量归属，不伪造发布版本或绕过计费。

`openKnowledgeSource` 在已授权会话中查找持久化记录 ID 和引用标签，校验原账号与空间，再向 Ground 发送发布版本、文档、修订、索引修订和片段五个精确 ID。未知标签拒绝打开。客户端通过会话投影读取无正文来源元数据，不接收凭据、隐藏提示词或任意存储 URL。

## 模型体验

### 当前请求知识

#### 模型看到什么

REQUIRED 在第一条模型请求之前根据当前已认领的可见用户问题检索。AUTO 仅在模型按需调用时检索。两者每轮最多两次；OFF 不提供知识工具。工具参数只有查询，工具结果只有状态；必需动态上下文承载有界、不可信的证据和绑定所属轮次及查询的标签。空结果与失败状态保持区别。REQUIRED 没有当前可用证据时，会在模型生成前确定性结束本轮，并显示带错误码和下一步建议的错误。补充查询失败只有在仍有已授权当前证据时才可继续；AUTO 保持显式降级。

必需上下文在 pre-step 之后刷新。旧运行时快照通过有日志的原生消息替换，仅移除 `OFFICIAL_EXPERT_KNOWLEDGE` 段并保留其他段。必读证据事件保存绑定、原账号与空间、操作预占、顺序、精确来源、预算和实际渲染上下文。历史标签不使用后续查询的来源映射。

Host 从持久化对话投影当前专家与账号空间边界内的前序可见用户/助手文字，最多八条、每条 2000 字符。压缩保留这些可见历史；模型专用替换、推理、工具内容和运行时资料快照均排除。AUTO 在首条持久化检索凭据之前的未定归属回合会被排除。向检索服务发送历史助手文字前，同样检查全部来源关系的当前权限。

#### Token 影响

冻结角色附加在原生提示词中。启用知识检索的专家还会收到系统指令：资料事实与方法使用精确的方括号来源标签，不编造来源链接或缺失原文，并区分创作示例与资料事实。证据按 UTF-8 字节保守上界控制在配置 token 额度内，并为封装预留空间；补充检索不能通过工具结果重复放入正文。较小预算可能截断证据或拒绝装载，并提示下一步。FIXED 在提示词与能力预算之前选择真实 Host 模型；Ground 在分发时仍负责最终校验。

#### KV 缓存影响

替换旧证据快照会改变请求序列，可能降低前缀缓存复用。原始记录保留在受保护会话日志中。重放与压缩保留精确来源关系，在重发模型前重新授权，不静默读取新文档。已发送的事实无法撤回。

## 完整技能包

技能会话使用标准预设已有的文件与命令工具。`skill`先列出冻结的摘要，调用时返回所选说明和资源目录。准备技能文件不会执行脚本或安装依赖。

Host通过 `packageFormat=2` 向Ground请求完整包。v2版本声明每项文件的相对路径、字节数、SHA-256和执行标记，以及排序元组生成的包摘要和容量规则。旧的说明与参考文件响应仍受支持；不支持或损坏的新格式响应不能退回旧格式加载。Ground对读取新格式包的旧客户端明确提示更新。

完整执行副本位于所选真实工作区的 `.mmp/runtime/skill-packages/`，不在本地技能发现目录中。Provider在公布资源目录前核对所有文件身份，读取下载流时限制字节数，并拒绝符号链接根目录。目录准备失败会清除失败缓存，修正目录后可重试。每个路径片段最多255个UTF-8字节，相对路径总长最多512个UTF-16代码单元，与Ground保持一致。复用前重新核对声明原文件；原文件改变时建立新的已核验副本，旧副本仍归Provider所有并在释放时清理。切换选择会取消准备过程，后续模型步骤在授权前等待清理。各Provider独立拥有其目录，不跨会话共享可写副本。

协议上限为500文件、展开10MiB、主说明100KiB。`skillMaxFiles`、`skillMaxTotalBytes`、`skillMaxInstructionBytes`可缩小本地额度。资源位置通过现有技能工具结果进入模型；实际文件读取和脚本命令沿用原工具权限及日志。包文件不增加初始目录token，已加载说明和后续工具结果按实际内容占用上下文，不另设KV缓存策略。

## 已知限制与后续工作

精确历史正文校验去重并串行执行，随后通过服务端单条 statement snapshot 同时授权全部绑定与来源。`maxHistoricalSources` 默认最多 128 个不同来源或绑定，超限停止重发并提示新开会话。授权不调用嵌入或重排服务。来源缺失、账号变化、预览过期或来源关系变化都会阻止重发，包括基于这些资料生成的摘要。

工程验证使用模拟 Ground 与模型响应。真实供应商语义质量、账单和客户账号验收需另行验证。旧知识预览必须迁移至新知识发布版本或显式使用 KNOWLEDGE_CORE/OFF；已有已发布旧专家继续使用原路径。Ground 内部直接委派新 REQUIRED/AUTO 知识专家仍不受支持。

Ground 发送前完成 body fitting 后，会由会话所有者再次核对有日志的完整证据段；证据缺失或被改动时阻止 HTTP，绝不发送未记录的节选。录制验证包含 `snapshots/sdk/official-expert-knowledge` 正式 `sdk` profile 场景和 Python SDK 的 `sdk-official-expert` 投影。两者恢复已录制的专家绑定，运行真实 Harness，仅模拟外部账号、Ground 与模型边界。
