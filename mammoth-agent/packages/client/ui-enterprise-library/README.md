# ui-enterprise-library

Web and desktop client entry for the single ground library via its connection-protected same-origin `/ground-library/*` Host transport. The Host forwards only allowlisted operations to Ground `/api/library/*`, never exposes its JWT and refuses account switches.
The left sidebar opens the library panel. The composer `+` action opens a dedicated library dialog with Recent, My files and Shared views, name search, folder navigation, paging and temporary multi-selection. Confirmation atomically replaces the library selection in the Session captured when the dialog opened and restores the composer caret after the selected files; cancellation preserves its draft. The panel action "用于 AI 对话" puts a ready version on the current draft, creating a Session only when none is open. The `@` menu uses the same node/version identity: duplicate selections stay once and explicitly selecting a newer version replaces the prior selection. Nothing sends until the user submits.

Submission sends structured library identities alongside the original question. The account Host authorizes and reads each exact version through `/api/library/open`, validates the account again for the complete batch, and stores each model excerpt as a separate text block with reference metadata. Missing, refused or empty sources reject the submission without clearing the draft. History and pending messages render file cards and the original question; model excerpts remain in the durable log and model request, while copy and Markdown export use file links instead. Pasted text is not a controlled citation. Ambiguous legacy mixed-text messages remain unchanged.

My files and Shared have independent sidebar trees, including their own recursive category queries, folder toggles and paging. Titles toggle their roots; returning from another category expands that root. Search results and recycled items stay on the left. Recent is a navigation entry whose paged file list occupies the right pane; selecting a recent file uses the same preview, and closing it returns to that list. Browsing rows have no selection checkboxes; multi-selection belongs to the composer picker. Folder titles and manageable nested folders have a right-aligned plus menu for New folder, Add link and Upload, with the destination captured from that folder independently of the active category. The right pane displays the selected original version without a directory table or preview modal. Collapsing a tree preserves subfolder and preview state. The preview header shows the file-format icon and filename with actions; version number and file size are omitted.

The root-scoped document.preview.bytes Factory renders complete, authorized version bytes as Markdown, code, static sandboxed HTML, PDF pages, read-only workbooks, images or media. Word and PowerPoint use the account Host’s existing Office-to-PDF converter. The immutable original filename selects the format even after display renames or cross-format replacements. Unsupported files and conversion errors remain explicit, and downloads remain available. Font diagnostics stay in conversion metadata without a library banner. PDF and converted Office pages fill the preview width on a white background without outer page padding, gaps or shadows. AI readiness is separate from visual preview and follows the selected version.

The directory divider highlights on hover or keyboard focus. Dragging adjusts its width between 200 and 480 pixels and remembers it on this device; the default is 280 pixels. Arrow keys adjust by 16 pixels, and Home/End select the limits. Narrow layouts reserve space for the preview; the mobile vertical layout hides the divider. Reaching the minimum width keeps the directory open.

The native panel supports explicit multi-file save, folders, URL-only links, rename/move/download, version history/replacement, visibility, recycling, restore, purge and parse retry. Temporary local chat attachments are not uploaded by this package. Saving into the library stays an explicit library action. New items at the personal root are private; items created at the Shared root or inside a shared folder are enterprise-visible immediately. Nested creation and uploads inherit the server folder visibility. Sharing or unsharing a folder confirms the server-reported count and revision and changes all nested items atomically. Moving private items into a shared folder requires confirmation. Visibility does not grant peers permission to edit another owner's items.

## Model Experience

An `@` library chip serializes to a selected node/version request. The Host supplies one untrusted excerpt block containing the server-returned file name, version id, locator and quote, including any truncation warning. The model sees that block only after the user sends the draft. The package adds no tool and does not call a local model provider.

## Known Limitations and Deferred Work

Desktop packaging is not exercised here. Web and desktop share the web-app composition. A signed-in Ground OIDC account and trusted Host connection are required; cross-origin direct browser calls are not used. OCR, spreadsheets, and ZIP contents remain unavailable as AI excerpts where the server reports download-only; supported spreadsheets still have a visual preview. Real-account acceptance and installed desktop packaging are separate from controlled Web tests.


## Member enterprise selection

The panel discovers only real active enterprise memberships through the protected Host `context` route. Selection is explicit, including for platform administrators, and never changes the Admin or browser SSO credential. The account Host holds the library-only member credential and supplies it consistently to previews, selected source reads and automatic search. It is discarded when the underlying account credential changes or the Host restarts. No enterprise is created or chosen implicitly. Platform membership does not enable Console access. Ground revalidates membership and the own-private/shared reference policy for every source read; management access to other members' private files is not model permission.
