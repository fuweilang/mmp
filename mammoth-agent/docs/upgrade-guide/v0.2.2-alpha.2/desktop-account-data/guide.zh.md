# 桌面客户端账号数据隔离

[English](guide.md) | 中文

## 变更

桌面客户端为每个已验证的登录服务、企业和用户使用独立的 `$MMP_HOME/desktop-accounts/<身份哈希>` 目录，会话、项目登记、附件和默认工作区文件一并隔离。切换账号时先停止旧 Host，清空应用页面和浏览器存储，再启动所选账号的 Host。切回原账号会恢复该账号的本地历史。本次不增加云端同步。

此前桌面客户端读取共享的 `$MMP_HOME/sessions` 和 `$MMP_HOME/storages`。这些文件和已有项目文件夹完整保留，但不会自动归给下一位登录用户。未登录启动使用独立的临时身份数据目录。登录凭证和部署配置仍使用原有安装位置。

## 迁移

1. 安装新版客户端并登录，系统会自动创建账号专属数据，无需修改配置。
2. 使用账号 A 新建会话和项目，确认登录账号 B 后看不到它们。切回 A 并重启客户端，确认 A 的历史仍可使用。
3. 保留原有 `$MMP_HOME/sessions`、`$MMP_HOME/storages` 和项目文件夹。如需恢复旧历史，应先确认其归属，再单独规划迁移；不要把共享存储整体复制给任意账号。
