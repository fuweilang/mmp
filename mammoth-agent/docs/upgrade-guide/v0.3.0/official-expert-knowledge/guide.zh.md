# 官方专家知识与预览会话

[English](guide.md) | 中文

## 变更

Host 协商 Ground 执行协议 2，并接受未变的旧协议响应。新知识会话持久化必读 `official-agent/knowledge` 事件、冻结执行策略，以及清除旧证据上下文的原生消息替换记录。不认识该事件的旧读取方必须拒绝会话。预览绑定的发布版本为 null，并使用不可变预览身份。旧会话日志仍可读取，不会因字段缺失而假定存在新证据。

FIXED 专家在 Host 预算计算之前选择冻结模型。显式云模型不可用时失败，不静默切换。预览用量使用 `x-mmp-expert-preview-id`；已发布专家继续使用版本归属头。

## 迁移

1. 创建新知识或预览会话之前，升级 Ground 至执行协议 2，并升级所有 Host 与会话读取方。保留所有已存会话世代，不降级包含必读证据事件的会话。
2. 在受支持的 `mmp` 配置中保留标准预设与图库插件。只有部署需要不同的有界历史授权上限时才修改 `maxHistoricalSources`，默认值为 128。
3. 使用配置的 Host 地址及 `expertPreview`、`expertId` 参数打开管理预览，并选择已有工作区。Ground 会重新检查创建者权限和 30 分钟有效期。
4. 验证 REQUIRED 证据进入第一条真实模型请求，引用重新打开原始五 ID 来源，且历史资料被撤权或不可用时阻止重发。达到历史授权上限时新开会话；固定模型不可用时选择可用模型或重新创建专家快照。

REQUIRED 没有当前可用证据时，现会在模型 HTTP 前以不同错误码和明确建议结束本轮。补充查询失败只有在仍有有效当前证据时才可继续。Ground 最终发送检查也会拒绝任何改动了完整已记录证据段的拟合请求；请开启更短的新会话或由管理员配置更大上下文模型。
