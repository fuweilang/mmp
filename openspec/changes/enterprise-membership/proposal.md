# 企业会员版本

专家广场按企业版本放开。标准版、专业版、旗舰版。版本挂在企业上，不挂在个人。

## 已定

- 标准版永久，是默认版本。老企业保持标准版。
- 专业版、旗舰版从支付成功当天起算一年。同一版本未到期续费，从原到期日往后延一年。专业升旗舰，从支付当天重新算一年。
- 专家有最低可用版本。新专家默认旗舰。企业版本不低于它才能用。
- 广场返回全部已发布专家，并带 `locked`。不够等级不从列表去掉。
- 新对话和已打开的对话，版本不够都拒绝，错误码 `MEMBERSHIP_REQUIRED`。
- 没选企业，或当前是猛犸总部，不拦。
- 只有支付成功才写订单。同一支付单号只升级一次。未支付不落库。只认微信和支付宝。
- 不建人民币钱包。AI 币充值不动。
- 不做发票、对公、待支付、取消、重复支付状态机。

## 不做（后两期）

- 总后台页面：专家下拉、套餐与定价、企业管理里改版本。
- Web、客户端、控制台的置灰和扫码。
