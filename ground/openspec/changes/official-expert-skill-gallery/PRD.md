# PRD：专家广场＋技能（第一版）

- 「入口」改成「专家广场」，Tab 为「专家」「技能」。公开内容只有启用/停用，没有安装。
- 卡片只有名称、简介、分类和新建动作；搜索与分类从简，不做推荐/评分。
- 专家和技能都新建会话：专家顶栏显示专家，技能顶栏显示技能；不修改旧对话。
- Admin 官方专家继续现有 CRUD，增加关联技能、分类和启停。技能优先 ZIP 上传，其次是超管表单；背后均为完整受管包。
- 关联技能给专家预备能力，不把全部正文塞进上下文。只有真正调用技能才加载其说明；资源按说明再取。
- 独立技能可启动通用 AI，原有文件/终端/联网继承标准模式；知识库权限不因广场可见而改变。
- 表单与 ZIP 对应同一字段包，package/resource 路径由底层处理，不做公共工具注册或沙箱编辑。
- 旧系统只挑资料来源；不做旧接口/数据/权限/包格式兼容。
- 不做用户上传、安装、卸载、私有权限、审核、评分、交易、复杂版本与测试验收。

详细字段、流程、接口、数据和协调分工见 `design.md`、`tasks.md`；验收场景见 `specs/`。
