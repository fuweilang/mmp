# enterprise-library

企业统一资料库首期。一套服务端数据，Web 资料库、企业 Console、平台 Admin 读同一批记录。不是各端互相同步的副本。

## 背景

中台已有 `kb*` 知识库（控制台上传、对话检索）。它默认全员或指定成员可见，没有私人/企业共享、版本、回收站、代管审计，也不能当作终端资料库。本 change 不改 `kb*` 的行为。

终端 Web / 桌面在 `mammoth-agent`（原 deepseek-harness）。其左栏和对话框是 Cordis 插件槽位，带词典、覆盖率和快照门禁。本 change 不改这些插件，避免把未接入的侧栏说成完成。

## 目标

- 逻辑企业、所有者、权限与物理存储分开。正文和元数据在中台，不进智能体临时工作目录。
- 租户只取登录态。下载、预览、解析、问答、引用打开都重新鉴权。
- 私人默认仅本人。企业管理员不能默认读他人私人正文。变为共享必须明确确认。
- 文件夹移动不改变可见性。同名上传不覆盖。替换产生新版本，旧引用仍指向旧版本。
- 回收后停止新检索和源下载。恢复保留原 ID 和版本，不自动公开。彻底删除后来源不可用，不改指向新版本。
- 允许的类型、单文件大小、容量口径、回收保留有明确规则，用环境变量，不新做配置后台。
- MD、文字型 PDF、DOCX 可提取。PPT、Excel、ZIP、老版 Office 标仅下载。HTML 不执行。ZIP 不自动解压、不进检索。
- 问答只把权限内、有界摘录交给云端模型池。引用带 fileId + versionId + 真实定位。没有可靠页码就不写页码。
- 临时会话附件不自动入库。选中资料只挂到输入框，不自动发送。

## 非目标

- 生产发布、合并、改用户本机未同步的目录。
- 复杂团队空间、公开匿名链、全站抓取、在线 Office/MD 编辑器、扫描 OCR、Excel 精确计算、ZIP 内容检索、向量库、自动全库检索。
- 本机 BYOK、Ollama 或其它本地模型作为正式路径。
- 把公开的第三方 Mindspace / 本地 RAG 装进仓库。本环境未验证其许可、兼容和云端适配。
- 在 mammoth-agent 里新做插件槽位。缺的是原生左栏和对话框「+」，见 tasks 的未完成项。

## 方案摘要

| 项 | 决策 |
|----|------|
| 数据 | 新表 `library_*`，与 `kb_*` 分开 |
| 身份 | JWT `tenantId` + 成员关系。请求里的 tenant_id 不采用 |
| 私人 | `PRIVATE` 仅所有者；代管要单独授权、到期、可撤销、写审计 |
| 共享 | `ENTERPRISE`，同租户成员可读。默认上传是私人 |
| 存储 | `LIBRARY_DIR` 下 `tenantId/versionId.ext`，拒绝路径穿越 |
| 模型 | 只调现有云端网关，`model=auto` 或池内引用 |
| Web | `/library`，沿用中台 Vue / Element Plus |
| Console | 同一页面，侧栏入口。仍看不到他人私人正文 |
| Admin | 容量、数量、状态；代管授权。默认不看正文 |
