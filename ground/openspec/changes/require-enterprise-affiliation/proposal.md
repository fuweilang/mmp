# require-enterprise-affiliation

业务用户必须有企业归属：console/agent 自助注册、admin/console 加人不得产生无企业账号；无企业归属的业务账号禁止登录。`/console/members` 菜单与页标题统一为「成员管理」。

## 背景

系统按企业隔离；无归属账号无法进入有效工作区，也不应继续登录。平台超管/平台管理员仍可无企业（平台身份）。

## 范围

- 前端：`/console/members` 侧栏、路由 title、工作台入口文案 →「成员管理」
- 后端：注册必须有企业名；admin 创建/改绑非平台账号必须有企业；解绑全部企业仅平台账号；业务账号无成员关系则登录拒绝
- console 加人：仍依赖当前企业上下文（无企业不可加人）

## 非目标

- 不强制平台管理员绑定企业
- 不改 Octop 影子用户字段
- 不推 git / 不发版

## 验收

1. 侧栏与页标题显示「成员管理」
2. 自助注册缺企业名被拒
3. admin 创建非平台角色未选企业被拒
4. admin 对非平台账号 `tenantId: null` 被拒
5. 无任何企业成员关系的业务账号登录返回「账号未归属任何企业」
