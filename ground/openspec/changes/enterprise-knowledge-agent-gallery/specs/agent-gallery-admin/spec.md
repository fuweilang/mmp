## ADDED Requirements

### Requirement: 官方智能体可发布并授权
平台 Admin SHALL 允许具备权限的管理员维护草稿、冻结发布版本、下架并管理试点企业开通。

#### Scenario: 编辑已发布智能体
- **WHEN** 管理员修改草稿
- **THEN** 已发布版本保持原配置，直到管理员明确发布新版本

#### Scenario: 撤销企业开通
- **WHEN** 管理员撤销企业对智能体的使用权
- **THEN** 该企业的后续会话启动及执行请求被拒绝

### Requirement: 企业授权固定到冻结版本
系统 SHALL 在开通时保存企业的智能体版本，并允许管理员显式升级或回滚。发布新草稿版本 SHALL NOT 自动改变已有企业的固定版本。

#### Scenario: 发布后选择历史版本
- **WHEN** 管理员将试点企业从当前版本切换到同一智能体的历史版本
- **THEN** 后续新会话使用所选历史版本，且系统记录企业与版本变更审计

#### Scenario: 下架官方智能体
- **WHEN** 管理员下架已发布智能体
- **THEN** 系统停止该企业智能体的新受控会话，保留历史版本与授权记录供审计和后续恢复
