# 企业知识库与智能体广场一期

## Why

企业需要在 Console 维护自己的资料，在猛犸智能体里直接用资料完成工作。旧平台有可复用的智能体定义和资料解析经验。MMP 已有企业权限、知识库管理和检索接口，仍需验证并打通到当前 Harness 会话的完整路径。

## What Changes

- 企业 Console 复用现有知识库，提供上传、解析状态、文档管理和授权。
- Mac 客户端与 Web 共用知识库使用入口和原生智能体广场。用户可以浏览、搜索、查看简介与开场问题，并在当前终端开聊。
- 平台 Admin 管理官方智能体的草稿、版本发布、下架和试点企业开通。
- 选一个通用智能体和一个企业资料型智能体验证闭环。试点阶段手工开通。

## Capabilities

### New Capabilities

- `enterprise-knowledge`：企业资料管理、授权检索与回答引用。
- `agent-gallery`：Mac 和 Web 的智能体浏览、搜索与开聊。
- `agent-gallery-admin`：官方智能体版本发布及试点授权。

## Impact

- Ground：Console、Admin、企业权限、知识库索引、官方目录和发布授权接口。
- mammoth-agent：共享界面、会话入口、知识库检索工具及官方智能体执行配置。
- 旧平台：作为只读盘点和试点定义来源。

## 非目标

一期不做自助支付、会员套餐、单智能体售卖、Skills Hub、个人知识库、旧平台整库迁移或多智能体编排。商业化在试点后单独立项，继续沿用现有模型用量计费。
