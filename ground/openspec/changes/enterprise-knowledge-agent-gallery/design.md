# 设计

## 入口和数据归属

| 入口 | 职责 |
| --- | --- |
| 企业 Console | 企业管理员上传、分类、更新资料和管理读权限，配置指定智能体可检索的资料范围。 |
| 平台 Admin | 维护官方卡片与执行配置，发布冻结版本、下架、开通和撤销试点企业。 |
| Mac / Web | 共享广场页面和聊天使用入口。按当前企业显示目录，搜索、看详情、点开场问题开聊，在聊天里选择资料和查看出处。 |

Ground 是企业知识库、官方目录和授权的权威。优先复用现有文件、权限及检索接口。先用真实 DOCX、PPTX、可提取文本的 PDF 校验解析质量，再决定复用老平台哪些解析能力。原件、索引与引用按企业隔离。

## 运行路径

1. 登录后由服务端核验当前企业和成员身份。上传资料后可看到处理中、可检索或解析失败。
2. 普通会话可以显式选库。官方智能体会话还需同时满足企业已开通、智能体绑定范围与成员文档权限。服务端在每次执行及检索时校验，空范围默认不查库。
3. Harness 获取获准的片段和来源，按现有云端模型路径生成答案。出处保留文件和可定位信息，打开来源时再次校验访问权限。无相关资料时说明未找到依据。
4. 从广场新建会话时固定智能体发布版本。草稿修改不影响已发布会话。下架或撤销后停止新的受控执行并明确提示。
5. 广场列表只下发公开展示信息。官方提示词及私有知识库配置由可信服务端执行路径读取，不进入公开目录或桌面发布包。桌面运行如何接到该路径，在第二阶段先验证再接产品入口。

## 迁移与试点

按老平台实际发布记录只读盘点，识别提示词、工具、知识库和编排依赖。试点先选文案润色大师及企业资料型产品答疑助手。显式映射资料和工具，缺失依赖的智能体不开放试点。平台提供官方能力，企业资料由企业自己授权。

## 官方目录与版本授权

- `official_agent` 只保存当前草稿和线上版本指针；`official_agent_version` 在发布时复制名称、简介、开场问题、执行提示词及工具范围，发布后不提供更新接口。
- `official_agent_tenant_grant` 以 `agent_id + tenant_id` 唯一，保存固定 `version_id` 和 `ACTIVE / REVOKED` 状态。重新开通复用原记录，撤销不删除历史。
- 新开通默认使用当前线上版本。发布新版本不改变已有企业的 `version_id`；Admin 必须显式选择版本完成升级或回滚。
- 下架只把智能体置为 `OFFLINE`，保留版本与授权。后续目录和受控执行必须同时核验 `PUBLISHED`、企业 `ACTIVE` 授权、企业状态及版本归属。
- Admin API 位于 `/api/admin/official-agents`，所有写操作记录 `audit_log`。审计只记标识、版本和企业，不复制提示词或企业文档正文。
- Prisma 迁移创建上述三表及状态枚举。种子只准备「文案润色大师」和「企业资料答疑助手」草稿，不自动发布或开通，也不覆盖管理员已有修改。

## 验收顺序

先验知识库单独可用及隔离，再验智能体发布和两端开聊，最后验试点企业开通、撤销、回滚及现有用量记录。试点数据用于后续确定套餐和单卖。

## 一期收口调整（2026-11-06）

- 试点智能体直接采用种子「文案润色大师」「企业资料答疑助手」，不再阻塞于旧 Coze 只读盘点。
- 租户隔离验收以多账号 API/客户端矩阵为准；不要求 Dev 内「切换企业」UI 自动化。
- 检索对整句问法增加词项变体（`lexicalQueryVariants`），避免「内部发布日期是什么？」类问句零命中。
- 商业化（套餐/单卖/Skills Hub）仍非目标，等真实试点反馈后再立项。
