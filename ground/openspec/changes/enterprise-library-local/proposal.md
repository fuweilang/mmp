# 企业统一资料库（本机实施）

## 目标
终端 Web、桌面、Console 与 Admin 共用 Ground 云端持久化资料与权限，形成上传—解析—手选—当前会话提问—版本来源闭环。

## 首期
原文件多选上传、私人/显式企业共享、文件夹、仅保存外链、搜索、重命名移动、新版本、回收恢复、下载、解析状态/重试、手选资料问答。MD/文字PDF/DOCX优先；ZIP不解压，Office不在线编辑。

## 排除
自动全库检索、在线Office、复杂团队ACL、OCR、Excel精确计算、自动附件入库、任何本地模型/BYOK、生产部署。

## 本机约束
基于2.0工作区现有大量未提交修改增量适配，不fetch/pull/checkout/merge/reset/stash，不commit/push/PR，不调用云端开发或其他队友。编辑前留选定源码备份和指纹，发现并发变化即停止该文件。
