## 2026-11-10 追加：成员资料

企业管理员（角色 `ADMIN` 或 `OWNER`）的 Console 资料库多了「成员资料」，路由 `/console/library/members`。普通成员没有这个菜单，直接打开会被送回「我的资料」。

进入 `/console/library/members` 先是成员表：姓名、手机号、资料数量和「查看资料」。名单来自 `GET /api/library/members`，只含本企业有效成员。点进去后地址带 `?member=<userId>`，左侧是这个人自己的文件夹，右侧是他的资料表，不再重复所有者列。文件列表沿用 `GET /api/library/items?view=members&owner=`。只带 `?folder=` 的旧地址会按文件夹所有者补上 member。这里可以预览、下载、重命名、移动、改共享范围、替换版本和回收，不能新建或上传。文件所有者不变。最近使用、我的资料、企业共享仍只按原来的范围过滤。管理员的回收站会多出自己有权回收的成员私人资料。终端里的资料选择器没有接入这个视图，不会因此自动把别人的私人资料交给 AI。

平台 Admin 不从「成员资料」拿权限。Admin 另有自己的入口，见下一节。

## 产品决定（已和用户对齐）

资料库分两段。

- 前半段是管理：上传、默认私人、确认后企业共享、处理状态、回收站、Console、企业管理员的成员资料、平台 Admin 选企业后直接管理。这是现在这期。代管授权不再是这条路径。
- 后半段是对话用法，有两种。第一种是手选：用户点一份「可供 AI 引用」的文件，挂到当前会话，发送时按资料 ID 和版本 ID 调用 `/api/library/open` 取摘录。这条已经做了，企业共享文件也可以手选。第二种是对话里直接说「帮我查泡泡玛特的商业分析」。工具 `library_search` 会在该成员能引用的资料里做字面检索。`askLibrary` 仍然只接收已经选好的版本 ID。向量检索仍不做。

权限按角色分开。普通成员只管理自己的资料。企业管理员在「成员资料」可以查看并管理本企业成员的资料，含尚未共享的私人资料，所有者不变。平台管理员只在 Admin 选中企业后直接管理该企业资料，并留下 `library_admin_result` 审计。不要把别人的私人正文因为管理员能打开页面，就自动送进管理员的对话。

共享目录是整棵继承。子项不能单独改回私人，接口保持 `409 SHARED_PARENT`。要单独变私人，先移出共享文件夹再改。要对整棵取消共享，对共享文件夹自己点「改回私人」。
