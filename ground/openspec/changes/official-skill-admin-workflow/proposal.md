# official-skill-admin-workflow

官方技能管理六项：简化新建/编辑、修复 ZIP、图片全链路、技能介绍、保存/启用、终端使用闭环。

## 已落地（本 change 之前）

- 管理页 `/admin/official-skills`：手填标识、用途、技能说明；ZIP 需 `skill.json` + `SKILL.md`；失败文案笼统。
- 图标：技能走 2MB 栅格；专家已是 5MB 简约上传，并会把 SVG/GIF 转成 PNG。
- 广场详情弹窗维护详细介绍、带短标签的开场白、更多说明；发现信息按 `expectedUpdatedAt` 防覆盖。
- 技能只有 `enabledAt` 启停，没有发布状态。终端已能 `createSkill` 绑定并预填草稿，详情按钮仍是线框，示例仍可能显示短标签。

## 目标

1. 标识系统生成、编辑只读；名称、一句话介绍、分类、技能指令统一。ZIP 与手填分开校验，字段红字加一条汇总 Toast。普通保存至少要有名称；启用才要求完整。
2. ZIP 先解析再保存。兼容根目录 `SKILL.md`、单层外层目录、Mac 无关文件。损坏、缺文件、多入口给出明确原因。失败不覆盖旧技能、包和来源。
3. 图片覆盖后台列表、编辑、广场、详情、任务标签。有图只显示图；无图或失败用默认图标。PNG/JPEG/WebP/SVG/GIF，5MB。SVG 安全转图，GIF 取首帧。
4. 「广场详情」改为「技能介绍」。选填详细介绍；最多 3 条完整示例问题，可增删排序；选填更多说明，默认折叠，空项不显示。
5. 三个入口更新同一技能的各自字段，并用 `expectedUpdatedAt` 拒绝静默覆盖。停用可保存或保存并启用；已启用只保存修改。启用失败保持停用并保留已保存内容。
6. 终端详情使用蓝色「使用技能」。示例进入新任务、真实绑定、可移除图名标签、预填完整问题，不自动发送、不调模型、不覆盖旧草稿、不造用户消息历史。无示例也可使用。
7. 平台管理员删除技能前必须确认。删除后管理列表和新使用入口不再出现；技能包、专家关联和历史任务仍保留。已启用也可以删。不是停用，也不另做审批。

## 非目标

- 不批量爬取技能图片，不做热度或人工排序。
- 不新增菜单，不做发布/下架，不照搬专家「保存并发布」。
- 不改写已有英文执行正文，不覆盖已记录的来源名称、来源介绍和许可。
- 不启用真实技能，不访问生产数据或凭证。
- 不修改、合并或推送 `4.0`，不自动合并本 PR。
