# official-skill-admin

## 新建与编辑

- 新建手填不接收管理员手写标识；服务生成唯一 `key`。编辑展示只读标识。
- 创建方式只在新建出现。ZIP 不要求手填技能指令。
- 手填与 ZIP 的错误分开。界面同时给出字段红字和一条汇总 Toast。
- 普通保存只强制名称。启用要求名称、一句话介绍和非空技能指令。

## ZIP

- 支持根目录 `SKILL.md`、单一外层目录，并忽略 Mac 无关文件。
- 损坏、缺 `SKILL.md`、多入口、空正文、不安全路径、不支持的附加文件各自有明确原因。
- 解析失败或标识冲突时不创建、不替换，不改旧包、旧来源和许可。
- 展示名修改不覆盖已有 `sourceName`、`sourceSummary` 和 manifest 里的许可。

## 图片

- 列表、编辑、广场、详情、任务标签使用同一显示规则：有效图只显示图，否则默认图标。
- 接受 PNG、JPEG、WebP、GIF、SVG，最大 5MB。SVG 转安全 PNG，GIF 只留首帧。

## 技能介绍

- 入口和标题使用「技能介绍」。
- 详细介绍选填。示例问题最多 3 条完整问题，可增删排序。更多说明选填，终端默认折叠，空组不显示。
- 不保存短标签和预设回答。显式清空示例后不从旧字段恢复。

## 保存与启用

- 编辑、替换、图标、技能介绍只更新自己的字段。
- `expectedUpdatedAt` 不一致时 409，不覆盖。
- 停用技能可保存或保存并启用。保存并启用先写入可保存草稿，启用失败则保持停用且不回滚该草稿；已有介绍或指令不被空白覆盖。已启用技能保存修改且不重复启用。
- 启用失败保持 `enabledAt = null`，并说明缺项。停用不删除历史。

## 终端

- 详情有蓝色「使用技能」。
- 示例打开新任务、绑定该技能、预填完整问题、可移除带图标签。
- 不自动发送，不调用模型，不覆盖已有未发送草稿，不写入空的用户历史。
- 没有示例时仍可使用技能。
