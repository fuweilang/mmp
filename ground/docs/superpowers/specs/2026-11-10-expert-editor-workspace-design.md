# 专家编辑工作台补齐

本次是已获用户授权的 Monica 参考方案的界面纠偏。用户指出点击编辑仍为旧页面。实测旧入口打开 720px 纵向弹窗，知识、模型配置附加在底部，真实预览另开窗口，未满足截图中的配置与试聊并排流程。

直接把现有新建 / 编辑入口改为全屏三栏工作台：左栏「个性化」以专家指令为主体，基本信息、角色、流程、交付要求可展开维护；中栏「能力」包含聊天模型、云端工具、方法技能、知识发布版本及检索设置；右栏「预览」先显示专家卡片，点击「保存并试聊」保存当前草稿、创建已有不可变预览，并嵌入标准 Host 会话。复用正式检索、模型与出处，不另造聊天接口。

保存仅保存草稿并停留，发布仍显式确认。编辑后已有预览不变，显示「配置已修改」并要求用户重新试聊。关闭未保存修改需确认；异步保存 / 预览中禁止切换编辑对象或关闭。首期开启新知识核心的空白新建表单，旧专家沿用原配置，不能静默迁移旧知识。所有密钥和知识切块由既有独立管理页面维护。

布局借鉴截图，沿用猛犸品牌；不照搬 Monica 的商标与未实现功能。较窄窗口三栏可横向滚动；手机顺序展示可滚动面板，所有功能可达。预览仍是完整标准 Host，若管理员未完成 Host 登录 / 工作区选择，在右栏按原流程完成，并提供新窗口入口。

实施取舍：沿用旧弹窗继续加字段无法修复此次验收问题；单独重写一套对话会复制权限、计费与来源逻辑。选择全屏编辑工作台 + 真实 Host 嵌入，代价是预览仍保留标准会话界面的工作区与导航。

范围仅 Vue 编辑与预览 UI，不改后端、会话格式、生产服务和现有资料。用户原有验收窗口 / 未保存输入不主动刷新或关闭；新开已加载新构建的验收页面。
