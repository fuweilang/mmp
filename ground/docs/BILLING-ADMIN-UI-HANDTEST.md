## 手测路径

1. 超管登录 → `/admin/billing`
2. 确认三块顺序：配置 → 企业资金 → 对账折叠
3. 改采购单价并保存 → 刷新后仍在
4. 钱包表点「详情」→ 下方出现资金详情三 Tab；关闭后 query 清掉
5. 企业列表点「资金」→ 跳到本页并打开对应详情
6. 「调账」正/负数 → 余额变；详情内余额同步（若开着）
7. 「扫码充值记录」Tab 有数据或空态
8. 对账：选日期查询 → 厂商合计 + 模型明细；折叠可收起
9. 功能不丢：配置、钱包列表过滤、调账、企业资金、充值记录、对账 assumption/octopHint
