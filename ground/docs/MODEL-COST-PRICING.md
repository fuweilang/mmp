# AI币：固定面值与系统模型价格

Admin「AI币计价配置」只编辑两项：全局售价倍率（至少 1）和新企业开户赠送金额（人民币元）。1 元固定为 10,000 AI币，1 AI币是 0.0001 元消费额度，不固定对应 Token。旧的模型手填价、模型倍率覆盖、厂商平均价不再用于新计费。

例如赠送 5 元，入账 50,000 AI币；倍率 3 时，该消费额度用完约对应 1.6667 元模型采购成本。赠送延续现有业务：每个新企业开户一次，使用 `signup_gift:<tenantId>` 幂等键、独立 `signup_gift` 流水，非每个企业成员都再赠送一次。无提现入口，不返现。调整赠送金额不补发历史账户。

## 参考价由系统维护

当前支持直接连接 DeepSeek 中国官方 API 和 Kimi 中国官方 API 的已核验模型，包括本机启用的 deepseek-flash、deepseek-v4-pro、kimi-k3.1-pro。按**接入渠道 URL + 精确模型 ID**匹配；不能用代理同名模型套官方采购价。尚未支持的渠道或模型暂停企业付费调用，界面提示待支持，绝不默认为零成本。

官方来源：
- https://api-docs.deepseek.com/zh-cn/quick_start/pricing/
- https://platform.kimi.com/docs/pricing/chat
- Kimi 缓存写入：https://platform.kimi.com/docs/guide/context-caching
- 2026 节假日：https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html

在有计价请求时按日核验官方固定地址，4 秒超时，严格校验已识别表格/模型/币种/正数价格；不执行官网脚本。核验失败保留最近有效价格，最长七天；过期停止企业计费调用。参考目录持久化到 `system_price_catalog`，重启可离线使用仍有效的记录。支持表格内已登记模型的价格更新，新增厂商、模型或官网改版仍需工程适配，不能声称自动覆盖所有模型。

DeepSeek 按北京时间峰谷、周末与 2026 节假日选择参考价格，2027 日历需要更新后才能用于企业收费。该参考价用于平台售价计算，不承诺等同供应商账单最终实扣（如供应商协议折扣或跨峰谷结算）。Kimi 分别计算缓存命中及 5m/1h 缓存写入，写入用量读取上游响应头。

## 精确结算

参考成本 = ((输入 − 命中缓存) × 输入单价 + 命中缓存 × 缓存命中价 + 输出 × 输出价 + 5m 写入 × 5m 写入价 + 1h 写入 × 1h 写入价) / 1,000,000。

售价 = 参考成本 × 全局倍率。扣币 = ceil(售价 × 10,000)，使用 Decimal，在单笔请求最后向上取整到整数 AI币。计价快照保存模型、来源、核验日期、时段、单价、倍率、面值及实际用量，不回写历史账单。缺失/无效上游用量记为异常供核对，不用厂商平均价猜扣。上游成功后按实际用量结算可产生欠款，欠款阻止后续新请求。

平台/超级管理员跳过余额限制及扣币，但记录实际 Token。普通企业成员正常计费。采购成本和倍率不通过普通企业钱包接口泄露。

页面按各模型展示「1 元」「赠送金额」分别全用于输入或输出时的 Token 参考数，两列不可相加；真实对话还涉及上下文、缓存和逐请求取整。

## 旧面值等值换算

迁移 `20261104090000_fixed_ai_coin_denomination` 在数据库事务中锁定计费相关表，将旧余额及累计金额等值换成 10,000 面值；不足一个新 AI币的尾差向用户取整，消费金额不缩水。旧流水和已确认订单保留原始数字，流水 metadata 标记原面值；展示和汇总统一折算到当前面值。迁移增加 `denomination_conversion` 记录，保留旧余额与累计值。未确认充值单转换到新面值，已确认订单不重入账。

本地执行迁移前已备份相关数据到 `/tmp/ground-before-fixed-denomination.json`（仅当前用户可读），并执行事务回滚演练检查余额金额。生产发布须先停计费流量再执行迁移，避免旧进程的在途旧面值结算写入新余额；部署使用新后端后恢复请求。不可只替换前端。
